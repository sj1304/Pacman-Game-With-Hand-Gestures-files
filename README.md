# Pacman Game using OpenCV & Pygame

An interactive Pacman-inspired game built using **Python**, **Pygame**, and **OpenCV**.  
The game combines classic arcade gameplay with real-time computer vision controls using webcam input.

---
## Installation and Playing

1. Clone the repository
```bash```
  git clone https://github.com/YOUR_USERNAME/Pacman-Game.git
2.Open Python/Anaconda Terminal
3.Run the game
'''bash'''
  python pacman.py
4.Play and Enjoy!

## Features

- Classic Pacman gameplay
- Real-time hand/gesture control using OpenCV
- Collision detection and scoring system
- Enemy ghost movement logic
- Interactive game UI using Pygame
- Webcam integration for player movement
- Sound effects and animations
